# Retail Sales & Inventory Intelligence Dashboard

## Project Overview
This project is an end-to-end retail analytics solution built using Excel, PostgreSQL, SQL, and Power BI.

The dashboard analyzes:
- Sales performance
- Product trends
- Revenue insights
- Category contribution
- Customer metrics

## Tools Used
- Excel
- PostgreSQL
- SQL
- Power BI

## Key Features
- Interactive dashboard
- KPI analysis
- Sales trend visualization
- Product performance analysis
- Category-wise revenue analysis

## Files Included
- Power BI Dashboard (.pbix)
- SQL Queries (.sql)
- Cleaned Dataset (.xlsx)
- Insights Report (.pdf)
